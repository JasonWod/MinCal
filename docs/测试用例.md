# MinCal 测试用例与质量基线

> 版本：v1.1 ／ 日期：2026-10-26 ／ 适用：Tauri 客户端 + FastAPI 同步服务端
> 状态标记：`待测` `通过` `失败` `阻塞` `已自动化`
> v1.1 变更：服务端修复 15 项走查缺陷（F-01~F-11、F-13、F-14、F-16、F-17），新增后端 pytest 50 用例，详见 §3.4；F-12（tombstone GC）与 F-15（refresh 轮换/撤销）需基础设施，仍待后续。

## 0. 运行方式

| 目标 | 命令 | 说明 |
|---|---|---|
| 前端单元测试 | `cd client && npm test` | 60 个用例，约 2s，jsdom + fake-indexeddb |
| 前端测试监听 | `cd client && npm run test:watch` | 开发时常驻 |
| 前端类型检查 | `cd client && npx tsc --noEmit` | 已含在 `npm run build` |
| 前端生产构建 | `cd client && npm run build` | 必须绿 |
| 客户端联调 | `cd client && npm run tauri dev` | 真实托盘/窗口/权限 |
| 浏览器降级 | `cd client && npm run dev` | 无 Tauri API，走 fallback |
| 服务端启动 | `cd backend && .venv/bin/uvicorn app.main:app --reload` | 需 PostgreSQL |
| 服务端单元测试 | `cd backend && .venv/bin/python -m pytest -q` | **50 用例**（策略 + HTTP 契约），**无需数据库** |
| 服务端依赖安装 | `cd backend && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt pytest httpx` | 一次性 |

**手工用例执行约定**：P0=冒烟（每次改动必跑）｜P1=核心｜P2=一般｜P3=低。发现缺陷时在“结果”列记录 `失败(F-x)` 并关联第 3 节走查编号。
